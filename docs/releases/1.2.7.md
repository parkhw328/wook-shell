# 1.2.7 — 터미널 종료 문자 수정과 WinSCP 형식 SFTP 접속

## 변경 사항

- 원격 TUI가 대체 화면에서 일반 셸 화면으로 돌아올 때 남은 마우스 보고와 확장 인코딩을 해제합니다. 앱이 마우스 모드를 정리하지 않아 종료 후 좌표가 문자로 입력되는 경로를 수정했습니다. Ctrl+C 자체는 원격 앱으로 그대로 전달하며 화면을 벗어나지 않는 강제 중단까지 감지하지는 않습니다.
- `sftp://`·`winscp-sftp://` URL과 `/username=`, `/password=`, `/sessionname=` 실행 인자로 SFTP 탭을 바로 엽니다. `--sftp`·`--remote-path`도 지원합니다. 기존 창 전달, 저장 호스트 재사용, URL의 UTF-8 디코딩과 초기 원격 폴더 이동을 포함합니다.
- SFTP 실행 암호도 이번 연결의 일회용 DPAPI 레코드를 사용합니다. 작업 프로세스에는 식별자만 전달하고 저장 암호는 바꾸지 않습니다. 재접속에 일회용 암호를 재사용하지 않습니다.
- 지원 범위는 SFTP 접속입니다. FTP·SCP, 파일 URL 자동 다운로드, WinSCP 스크립트·고급 옵션은 지원하지 않습니다. 자세한 예시와 제한은 [SFTP 사용법](../sftp.md#실행-인자로-sftp-열기-windows)을 참고하세요.

## 검증

- 2026-10-16 사용자가 수정 개발 빌드에 대해 “잘된다”고 확인하고 새 버전 배포를 요청했습니다. 구체적인 환경·검사 목록이 제공된 것은 아니므로 자동화된 Windows 전체 회귀 검사나 새 버전 패키지 자체의 실행 검증으로 표시하지 않습니다.
- Linux Python 회귀 검사 20개 통과. 실제 패치된 세 대체 화면 전환 처리 코드를 실행하여 잔존 마우스 보고 해제와 정상 상태 보존을 검사했습니다.
- Windows x64 교차 빌드와 테스트 EXE 컴파일, 단일 EXE ZIP·내장 리소스·시스템 DLL 의존성·SHA-256 정적 검사를 수행합니다. 배포 manifest는 커밋된 소스와 Linux 교차 빌드 출처를 기록합니다.
- 실행 인자·IPC 회귀 검사와 SFTP 루프백 검사에 URL·초기 경로·기존 창 전달·일회용 암호 소비·터미널 미생성을 추가했습니다. 마우스 루프백 검사에는 구형 좌표 형식과 SGR 보고가 남은 종료 상황을 포함합니다. JavaScript 구문 검사 통과.
- 이 Linux 환경에서는 Windows CTest·SSH/SFTP/UI·IME·DPAPI·NGS 자동/실기 검사를 실행하지 않았습니다. 사용자 확인과 별도로 manifest의 Windows runtime 상태는 `not-run`을 유지합니다. macOS·iPad 빌드 및 GitHub Actions는 실행하지 않습니다.
