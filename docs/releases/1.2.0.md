# 1.2.0 — 연결 폴더와 순서 관리

- 왼쪽 연결 목록의 **+ Folder**로 폴더를 만들고, 우클릭의 **Rename folder / Delete folder**로 이름을 바꾸거나 삭제합니다. 기존 Group 값도 폴더로 표시합니다.
- 호스트의 **Move to folder**와 편집창의 **Folder**로 소속을 바꿉니다. **No folder**를 선택하면 폴더 밖으로 옮깁니다. 폴더 삭제 시 호스트와 열린 터미널은 유지합니다.
- **↑ / ↓**, 우클릭의 **Move up / Move down**, **Ctrl+Up / Ctrl+Down**으로 폴더·호스트의 순서를 바꿉니다. 호스트는 같은 폴더 안에서 이동합니다. 열린 터미널 탭은 기존 드래그 및 Move left / Move right로 정렬합니다.
- 빈 폴더, 접힘 상태와 순서를 저장하고 `.wshell` 백업에 포함합니다. 검색 중에는 접힌 폴더의 결과도 보여 주며, 검색을 지우면 접힘 상태를 복원합니다.
- 기존 탭 분리, SFTP 파일 드래그앤드롭과 삭제 확인 단축키를 포함합니다.

## 호환성

기존 호스트와 Group 설정을 그대로 읽습니다. 폴더는 한 단계 그룹이며, 폴더가 없는 호스트를 먼저 표시합니다. 기존 백업은 가져올 수 있습니다. 폴더 정보가 포함된 새 백업은 Windows 1.2.0 이상에서 복원하세요. 이전 Windows 및 현재 macOS·iPad 빌드는 새 폴더 레코드를 지원하지 않습니다.

## 검증과 제한

Windows 로컬 빌드, 핵심 검사 932개, 연결 폴더 UI 검사 77개, 스크롤바 UI 검사 66개를 통과했습니다. 실행 전달과 IME 검사도 통과했습니다. 폴더 UI 검사는 격리된 테스트 데이터와 Win32 메시지로 생성·이름 변경·취소·삭제, 순서 저장, 검색, 94개 연결과 최소 창 크기를 확인합니다.

이 PC에서는 SFTP codec 테스트 실행파일이 Application Control 보안 정책으로 차단되어 미실행입니다. 전체 SSH/UI 회귀 검사는 루프백 SSH 인증 및 SFTP 단계 이후 다른 앱이 전경을 차지하여 실제 마우스 대상 확인에서 중단되었습니다. 전체 회귀 통과로 표시하지 않습니다. 실제 탐색기 드롭·창 사이 드롭 위치 판정·다중 모니터 배율·NGS 수동 검증은 미실행입니다. Windows EXE는 미서명이며 macOS·iPad 및 GitHub Actions는 실행하지 않았습니다. 패키지 해시와 상세 검증 결과는 배포 manifest에 기록합니다.
