# 1.0.8 — Shift+왼쪽 및 방향키 수정키 호환성 수정

- Codex 등 터미널 앱에 Shift+왼쪽이 일반 왼쪽으로 전달되던 문제를 수정했습니다. 애플리케이션 커서 모드에서도 `ESC [ 1 ; 2 D`를 전송합니다.
- Shift·Ctrl·Alt 방향키는 기본적으로 xterm 수정키 인코딩을 사용합니다. 수정키 없는 방향키, VT52와 명시적으로 선택한 기존 모드는 유지합니다.
- 기존 연결에도 새 기본값을 적용합니다. 이전 `ShiftedArrowKeys` 설정은 자동 승계하지 않으며, 기존 동작이 필요하면 Host settings → Terminal → Keyboard에서 `Ctrl toggles app mode`를 다시 선택하고 저장하세요. [상세 설명](../modified-arrow-keys.md)
- [1.0.7의 Enter 스크롤 복귀](1.0.7.md)와 이전 개선을 포함합니다.

## 검증과 제한

- 2026-10-12 사용자 보고로 수정 후 정상 동작을 확인했습니다.
- Python 테스트 16개가 통과했습니다. 실제 패치된 방향키 인코더를 호스트에서 컴파일하여 네 방향·수정키 조합·일반/애플리케이션 커서 모드의 출력 바이트와 기존 모드 동작을 검사했습니다.
- Windows x64 EXE와 테스트 EXE를 Linux에서 교차 빌드하고 단일 EXE ZIP·해시·내장 리소스·시스템 DLL 의존성을 정적으로 검증했습니다.
- 이번 배포 EXE의 Windows UI·SSH 자동 실행 검사와 NGS 수동 검증은 미실행입니다. 인코더 테스트는 Windows 키 이벤트나 SSH 전송 전체를 실행하는 검사가 아닙니다.
- macOS·iPad와 GitHub Actions는 실행하지 않았습니다. EXE는 미서명입니다.
