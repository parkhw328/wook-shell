# 1.0.9 — SFTP 스크롤바와 파일 작업 단축키

- SFTP 로컬·원격 목록의 가로·세로 스크롤바와 모서리를 어두운 테마에 맞춰 밝게 튀던 부분을 수정했습니다. Windows 기본 스크롤 동작을 유지합니다.
- 파일 목록에서 **F2**로 선택 항목 하나의 이름을 변경하고, **Delete**로 선택 항목을 삭제할 수 있습니다. **F5**는 Refresh 버튼과 같이 로컬·원격 목록을 모두 갱신합니다.
- 이름 변경·삭제는 키를 누른 목록의 선택 항목에 적용합니다. 기존 삭제 확인창과 기본 No를 유지하며, 대화상자를 닫으면 원래 목록으로 포커스가 돌아갑니다.
- 연결·전송 등 작업 중에는 단축키를 차단합니다. Ctrl·Shift·Alt 조합과 경로 입력칸의 텍스트 편집은 별도로 처리합니다.
- Rename·Delete·Refresh 버튼과 상단 Shortcuts에 단축키 안내를 표시합니다. [사용법](../sftp.md#단축키-windows)
- [1.0.8의 방향키 수정키 호환성 수정](1.0.8.md)과 이전 개선을 포함합니다.

## 검증과 제한

- 2026-10-13 사용자가 SFTP 스크롤바·단축키 수정본의 테스트 완료를 확인했습니다.
- 배포 무결성 Python 테스트 8개가 통과했습니다.
- Windows x64 EXE와 테스트 EXE를 Linux에서 교차 빌드하고, 단일 EXE ZIP·SHA-256·내장 리소스·시스템 DLL 의존성을 정적으로 검증했습니다.
- SFTP 단축키 회귀 검사 코드를 추가했습니다. 이번 Linux 패키징 환경에서 Windows UI·SSH 자동 실행 검사와 스크린샷 검사는 수행하지 않았습니다. 사용자 테스트 완료 보고와 빌드 환경의 자동 검사 결과를 구분하여 기록합니다.
- NGS 환경의 별도 수동 검증, macOS·iPad 빌드와 GitHub Actions는 실행하지 않았습니다. EXE는 미서명입니다.
