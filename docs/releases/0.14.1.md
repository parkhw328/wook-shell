# 0.14.1 — 커맨드 창과 >_ 아이콘

실행파일과 작업 표시줄 아이콘을 주황색 커맨드 창 안에 `>_` 프롬프트가 있는 형태로 바꿨습니다. 차콜 배경과 주황색 브랜드 톤을 유지하면서 셸 앱임을 바로 알아볼 수 있도록 했습니다.

PNG 원본과 16·24·32·48·64·128·256px Windows ICO를 갱신했습니다. 앱 기능은 0.14.0과 같습니다.

Windows 로컬 Release 빌드와 CTest 4개, Python 도구 테스트 12개, 폰트 캐시·실행 인자·개인키 가져오기 회귀 검증이 통과했습니다. 단일 EXE ZIP, SHA-256, 시스템 DLL 의존성, 내장 리소스와 7개 아이콘 해상도를 검증했습니다. 32px 아이콘과 생성된 앱 화면도 확인했습니다.

SSH/UI 전체 통합 검증은 **미통과**입니다. 첫 실행은 비밀번호 재입력 phase 16에서 `Timed out waiting for hosted terminal windows.`로 종료됐습니다. 최종 아이콘으로 재빌드한 뒤 단독 재실행에서는 해당 단계를 통과했으나 phase 34에서 `Native click must hit the test window, never another application`으로 중단됐습니다. 실제 클릭 대상이 테스트 창이 아니라는 안전 검사 실패를 통과로 처리하지 않았습니다. 아이콘 외 앱 코드는 변경하지 않았습니다. NGS 환경 수동 검증과 macOS·iPad 빌드는 수행하지 않았습니다.
