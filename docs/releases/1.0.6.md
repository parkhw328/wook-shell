# 1.0.6 — SFTP 깜빡임과 전송 병목 수정

- SFTP 진행 표시를 갱신할 때 전체 화면 대신 하단 영역만 다시 그립니다. 메모리 버퍼에서 완성한 화면을 한 번에 표시해 배경과 글자가 순서대로 그려지던 깜빡임을 줄였습니다.
- Windows SSH 브리지의 타이머당 최대 64KB 입력 제한을 제거하고, PuTTY의 이벤트 기반 파이프 입출력과 송수신 흐름 제어를 사용합니다.
- 다운로드 수신부의 5ms 폴링을 overlapped I/O로 바꿔 데이터 도착 즉시 처리합니다. 프로세스 종료·120초 타임아웃과 취소 완료 처리를 유지합니다.
- 업로드는 최대 64개 요청을 유지하면서 응답마다 다음 요청을 보충합니다. 기존 16개 묶음 전체의 응답을 기다리던 대기를 제거했습니다.
- 진행률은 서버가 확인한 바이트를 기준으로 계산합니다. 잘못된 응답·취소·전송 실패 후에는 연결을 재사용하지 않습니다.
- Windows 성능 비교 도구에 업로드 측정과 양방향 파일 내용 검사를 추가했습니다.

## 검증과 제한

- Linux에서 공통 SFTP 코덱 회귀 검사 144개와 Python 테스트 13개를 통과했습니다.
- Windows x64 EXE와 테스트 EXE를 교차 빌드하고, 단일 EXE ZIP·해시·내장 폰트/브랜딩/라이선스·시스템 DLL 의존성을 정적으로 검증했습니다.
- Windows UI·SSH 실행 검사, 실제 화면 캡처, NGS 수동 검증 및 같은 서버·파일·네트워크에서의 WinSCP 속도 비교는 미실행입니다. 이전 1.0.5의 성능 수치는 이번 변경의 실측 결과가 아닙니다.
- ASan 검사는 Linux 호스트 런타임 라이브러리 부재로 실행하지 못했습니다.
- macOS·iPad와 GitHub Actions는 실행하지 않았습니다. EXE는 미서명입니다.
