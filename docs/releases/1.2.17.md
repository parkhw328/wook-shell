# 1.2.17 — 호스트 삭제와 공통 확인창 단축키 보완

## 변경 사항

- 연결 목록에서 Delete로 호스트·폴더 삭제 확인을 엽니다. 우클릭 삭제 메뉴에도 Del을 표시하고 동일한 삭제 명령을 사용합니다. 기본 선택 No와 열린 터미널 보존을 유지합니다.
- 공통 확인창의 Yes/No에 Y/N을 추가하고 OK·Cancel·Retry·Abort·Ignore·Try again·Continue에도 버튼에 표시한 문자 단축키를 제공합니다. 문자 또는 Alt+문자로 실행하며 Ctrl 조합과 키 자동 반복은 실행하지 않습니다.
- 기존 Enter·Esc·닫기 반환 의미와 SSH 호스트 키 전용 선택을 유지합니다. 입력칸과 터미널의 Delete는 기존 편집 기능을 유지합니다.
- Shortcuts 안내와 사용법을 갱신하고 공통 버튼·반복 키·호스트 삭제 취소/승인·열린 탭 보존의 Windows 회귀 검사를 추가했습니다.

## 검증과 제한

- Linux Python 회귀 검사 40개 통과. Windows x64 앱·테스트 EXE 교차 빌드, EXE·ZIP·내장 자산·DLL 의존성·해시 정적 검증을 통과했습니다.
- Linux 환경으로 Windows UI 실행·실제 키보드 입력·스크린샷·SSH/IME/DPAPI·NGS 실기 검사는 미실행입니다. 추가한 Windows 회귀 검사는 컴파일까지만 검증합니다. Windows에서 `node tests/ssh/message-integration.cjs`와 `node tests/ssh/connections-integration.cjs` 실행 및 생성된 화면 확인이 필요합니다.
- macOS·iPad와 GitHub Actions는 실행하지 않습니다. Windows EXE는 미서명입니다.
