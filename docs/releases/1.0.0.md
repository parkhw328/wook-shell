# 1.0.0 — wShell 공개 배포

Windows 공개 배포 버전을 1.0.0으로 올렸습니다. 베타 접미사 없이 제공하며, 문제와 개선 요청은 [GitHub Issues](https://github.com/parkhw328/wook-shell/issues)에 남길 수 있습니다.

- SSH·SFTP·로컬 셸, 탭과 분할 작업 공간을 단일 EXE로 제공합니다.
- 주황색 커맨드 창과 `>_` 아이콘을 사용합니다.
- 기존 0.14.1과 같은 앱 기능이며 버전 정보와 배포 안내를 갱신했습니다.
- SignPath 신청은 제출했지만 아직 서명 서비스를 연동하지 않았습니다. **이 배포의 EXE는 미서명입니다.**
- macOS는 기존 0.11.0을 제공하며 iPad는 보류합니다.

## 검증

- Windows 로컬 Release 빌드, CTest 4개와 Python 도구 테스트 13개 통과.
- 폰트 캐시, 실행 인자·기존 창 전달, 개인키 가져오기·실제 SSH 서명 회귀 검증 통과.
- 단일 EXE ZIP, SHA-256, 내장 폰트·라이선스·아이콘, 시스템 DLL 의존성과 다운로드 링크 검증 통과. EXE 파일·제품 버전은 모두 1.0.0입니다.
- SSH/UI 전체 통합 테스트는 **미통과**입니다. 이번 실행도 phase 34에서 `Native click must hit the test window, never another application`으로 중단됐습니다. 클릭 대상 안전 검사 실패를 통과로 처리하지 않았습니다.
- NGS 환경 수동 검증과 macOS·iPad 재빌드는 수행하지 않았습니다.
