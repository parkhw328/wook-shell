# 1.0.0 — wShell 공개 배포

Windows 공개 배포 버전을 1.0.0으로 올렸습니다. 베타 접미사 없이 제공하며, 문제와 개선 요청은 [GitHub Issues](https://github.com/parkhw328/wook-shell/issues)에 남길 수 있습니다.

- SSH·SFTP·로컬 셸, 탭과 분할 작업 공간을 단일 EXE로 제공합니다.
- 주황색 커맨드 창과 `>_` 아이콘을 사용합니다.
- 기존 0.14.1과 같은 앱 기능이며 버전 정보와 배포 안내를 갱신했습니다.
- SignPath 신청은 제출했지만 아직 서명 서비스를 연동하지 않았습니다. **이 배포의 EXE는 미서명입니다.**
- macOS는 기존 0.11.0을 제공하며 iPad는 보류합니다.

## 검증

1.0.0 배포 파일의 검증 결과는 배포 커밋에 기록합니다. 이전 0.14.1의 SSH/UI 전체 검증은 클릭 대상 안전 검사에서 중단됐으며, 이를 통과한 것으로 표시하지 않습니다. NGS 환경 수동 검증은 수행하지 않았습니다.
