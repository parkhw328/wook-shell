# 1.2.10 — SFTP 전송 속도 천 단위 표시

## 변경 사항

- 업로드·다운로드 속도를 `12,345.6 KB/s`처럼 천 단위 콤마로 표시합니다. 소수점 한 자리와 기존 속도 계산·단위(1 KB = 1,024 bytes)를 유지합니다.
- 반올림으로 천 단위를 넘는 값도 `1,000.0 KB/s`로 표시하며 시스템 로케일과 무관하게 소수점은 점을 사용합니다.

## 검증과 제한

- Linux Python 회귀 검사 28개 통과. 속도의 0·천 단위 경계·반올림·큰 값·소수점 콤마 로케일과 기존 uint64 파일 크기 표시를 검사했습니다.
- Windows x64 교차 빌드·테스트 EXE 컴파일과 배포 파일·내장 리소스·시스템 DLL·ZIP·해시 정적 검사를 수행합니다.
- Windows 데스크톱이 없어 실제 SFTP 전송·UI 실행 검사는 미실행입니다. macOS·iPad 빌드와 GitHub Actions도 실행하지 않습니다.
