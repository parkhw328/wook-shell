# wShell 0.5.1

- Windows: show Korean/IME composition directly at the terminal caret, using the terminal font, cell size, colors, and an orange underline. Keep candidate windows near the composition row, including after resizing.
- Send only committed text; preserve surrogate pairs, clear cancelled previews, and complete composition into the original tab on focus changes. Fix the Unicode `WM_IME_CHAR` fallback that previously treated characters as legacy byte pairs.
- macOS: accept attributed IME commits, report selection relative to marked text, refresh candidate coordinates, and reset composition state after a commit.
- Verify composition updates, cancellation, cell geometry and Unicode commits with automated native tests; verify exact Korean/emoji input through loopback SSH on both platforms. Screenshots use synthetic preedit. Physical typing with every OS IME/version is not covered by automation.

Windows remains a single `wShell.exe`. macOS remains a Universal `wShell.app` for macOS 13+; it is ad-hoc signed and not notarized. Settings stay in the existing user data directory. Backups exclude passwords and private-key files.
