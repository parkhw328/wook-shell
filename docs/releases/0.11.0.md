# wShell 0.11.0

## Windows 탭 탐색

탭이 표시 영역 밖에 숨겨져 연결이 종료된 것처럼 보이던 문제를 수정했다. 탭은 198→112 논리 픽셀로 줄어든 뒤 좌우 스크롤로 전환한다. 휠·가로 휠·좌우 버튼, 현재 범위/전체 개수, 전체 탭 메뉴를 탭 줄에 제공한다. 전체 목록에서는 이름과 주소, 활성 탭 체크를 확인할 수 있다.

스크롤은 활성 연결과 분할 대상을 바꾸지 않는다. 주기적인 상태 갱신은 사용자가 둘러보고 있는 위치를 보존하고, 탭을 선택하거나 창 크기를 바꾸면 선택된 탭이 보이도록 조정한다. Ctrl+Tab, 닫기, 재정렬과 분할 포커스 동작을 유지한다.

## Windows SSH 실행 인자

`wShell.exe -ssh user@host -P 2222 -pw "<password>"` 형태와 긴 옵션을 지원한다. 주소·포트·사용자로 저장 호스트를 찾고, 없으면 등록한 뒤 연결한다. 기존 호스트의 이름·별칭·폰트·고급 설정과 암호는 보존한다. `--name` 충돌은 오류로 처리한다.

전달한 암호는 DPAPI 사용자 범위의 일회용 레코드에 보관하고 소비 후 삭제한다. 자식 터미널에는 암호가 아닌 레코드 이름만 전달한다. 원래 실행 명령줄·셸 기록의 노출을 피하려면 `--password-stdin` UTF-8 파이프나 터미널 입력을 사용한다. 최초 호스트 키 확인, 불일치 차단, 인증 실패 후 수동 입력 규칙을 유지한다.

## iPad 빌드·설치 안내

iPad 버전은 `ios/VERSION`의 0.1.0으로 별도 관리한다. 기존 `ipad.yml`을 통한 시뮬레이터 검증과 unsigned arm64 IPA 생성을 유지한다. [iPadOS 26.6에서의 Derpy 검토](../ipad-signing.md)에 App Store 암호화 IPA와 개인 개발 서명의 차이, 무료 계정의 7일 제한, Sideloadly 자동 갱신 절차를 기록했다. 서명 완료 IPA나 실기기 설치 성공으로 표시하지 않는다.

## 검증 범위

- CTest: 탭 폭·스크롤 경계, 인수 파싱, 기존 호스트 재사용·충돌 거부, 계정·주소·포트별 DPAPI 범위와 일회용 소비, 기존 설정·백업·IME·SFTP 코덱.
- `launch-integration.cjs`: 배포 EXE로 PuTTY식 옵션·긴 옵션·유니코드 비밀번호 파이프의 실제 SSH 인증, 저장 파일 보존과 자식 명령줄 검사.
- `tabs_smoke.inc`: 최소/큰 창의 32개 탭, 양끝 버튼 상태, 휠 누적과 가로 이동, 키보드 전환·활성 객체 보존, 캡처.
- 기존 SSH/UI·분할 포커스·폰트·SFTP 검증 및 Windows/macOS CI, iPad 시뮬레이터 CI.

macOS UI와 실행 인자 지원 범위는 이번 Windows 변경에 포함되지 않는다. iPadOS 26.6 실기기 설치·키보드 입력은 사용자의 로컬 서명 후 확인해야 한다.
