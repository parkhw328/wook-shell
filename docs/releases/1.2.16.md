# 1.2.16 — SFTP 대용량 다운로드와 Explorer 드롭 개선

## 변경 사항

- 다운로드 전에 임시 파일의 디스크 공간을 예약하여 수신 중 반복 할당을 줄입니다. 예약을 지원하지 않는 파일 시스템은 기존 쓰기 방식으로 처리하며, 공간 부족·권한 오류는 전송 전에 알립니다. 기존 파일 보호·취소 정리·마지막 디스크 저장은 유지합니다.
- Explorer로 원격 파일을 끌어 놓을 때 비동기 파일 전달을 지원합니다. 드롭 반환 뒤의 내용 요청에도 다운로드 콜백과 임시 파일을 유지하고, 완료까지 UI 메시지를 처리합니다.
- Windows 복사 진행창을 강제로 요청하는 옵션을 제거했습니다. Explorer가 자체적으로 표시하는 복사 진행창은 나타날 수 있습니다. Explorer의 취소는 추가 실패 안내로 바꾸지 않습니다.
- 1.5GiB 파일의 다운로드·재업로드 크기와 SHA-256, 반복 SSH 재교환, 정지 위치와 네트워크·디스크 지연을 구분하는 검증을 추가했습니다. [상세 검증 절차](../sftp-transfer-validation.md)를 확인하세요.

## 검증과 제한

- 사용자가 수정본 확인 후 커밋·푸시·릴리즈를 요청했습니다. 구체적인 수동 테스트 항목이나 측정 결과는 제공되지 않았으므로 Windows 자동 검증 완료 또는 속도 정지 원인 확정으로 기록하지 않습니다.
- Linux 호스트 Python 회귀 테스트 40개와 JavaScript 구문 검사를 통과했습니다. 공간 예약의 64비트 크기·미지원 파일 시스템·공간 부족·권한 오류, 기존 요청 보충과 재교환 후 입력 재개 검사를 포함합니다.
- Windows x64 앱과 테스트 EXE를 Linux에서 교차 빌드하고 EXE·ZIP·내장 자산·시스템 DLL 의존성과 해시를 정적으로 검증합니다. 배포 manifest에 실제 소스 커밋, 깨끗한 소스 상태와 빌드 도구 정보를 기록합니다.
- 이번 환경에서 Windows 실행·SSH/UI/Explorer 자동 검사와 실제 1.5GB 전송 재현, NGS 실기 검사는 실행하지 않았습니다. 속도가 0으로 내려가는 현상의 해소 여부는 Windows에서 확인해야 합니다. Windows EXE는 미서명입니다.
- macOS·iPad 빌드와 GitHub Actions는 실행하지 않았습니다. 기존 버전별 배포 파일은 보존합니다.
