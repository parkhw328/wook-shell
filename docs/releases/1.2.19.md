# 1.2.19 — Windows 메뉴바와 프로젝트 문서 정리

## 변경 사항

- 상단 작업 버튼을 `File · Host · Session · View · Tools · Help` 네이티브 메뉴바로 교체했습니다. 기존 버튼 줄이 차지하던 공간을 작업 영역에 돌려주고 공통 글꼴·색상을 적용했습니다.
- 저장 호스트 명령은 Host, 활성 탭 명령은 Session으로 묶었습니다. 선택·연결 상태에 따라 항목을 비활성화하고 상태 표시줄에 적용 대상을 안내합니다. 설정 백업은 File, 단축키·라이선스·About은 Help에 있습니다.
- `F10`, `Alt+F/H/S/V/T/E`, 방향키·Enter·Esc 메뉴 탐색을 연결했습니다. 내장 터미널에서도 메뉴 키를 작업 공간으로 전달하며 Ctrl/Shift 조합·AltGr와 기존 탭 단축키는 보존합니다.
- 개발·배포 규칙은 `rules/rules/`, 제품·기능 요구사항은 `rules/requirements/`로 분리했습니다. [프로젝트 지도](../../rules/README.md)에서 기능별 요구사항·구현·검증 위치를 확인할 수 있습니다.

기존 명령의 새 위치와 키 사용법은 [Windows 메뉴바 안내](../workspace-menu-bar.md)를 확인하세요. F10과 위 Alt 조합은 앱 메뉴용으로 사용되므로 원격 프로그램에 전달되지 않습니다.

## 검증과 제한

- Linux Python 회귀 검사 57개를 통과했습니다. 메뉴 키 관련 3개 검사는 작업 공간·터미널이 공유하는 실제 키 판별 코드로 메뉴 조합과 AltGr·수정 키·일반 입력의 구분을 검사합니다.
- Windows 앱과 테스트 EXE는 Linux에서 교차 빌드합니다. 단일 EXE ZIP, x64 시스템 DLL 의존성, 내장 폰트·아이콘·라이선스, 해시와 소스·도구 출처의 배포 검증 결과는 [manifest](../../release/1.2.19/manifest.json)에 기록합니다.
- Windows 실제 메뉴 표시·마우스·F10·Alt 키·포커스 복귀·접근성·다중 DPI·화면 캡처, SSH·SFTP·IME·DPAPI·CTest와 NGS 실기 검사는 Linux 환경이므로 **미실행**입니다. 컴파일된 UI 회귀 검사를 Windows에서 실행해야 하며, 기존 화면 이미지는 이전 UI 예시입니다.
- Windows 후속 확인 명령은 `node tests/ssh/connections-integration.cjs`, `node tests/ssh/focus-integration.cjs`, `node tests/ssh/message-integration.cjs`, `node tests/ssh/integration.cjs`와 CTest입니다.
- macOS·iPad 빌드와 GitHub Actions는 실행하지 않았습니다. Windows EXE는 미서명입니다.
