# 1.1.1 — SFTP 삭제 확인 단축키

- SFTP 로컬·원격 파일 목록에서 Delete를 누르면 `Y`로 삭제하고 `N` 또는 `Esc`로 취소할 수 있습니다.
- 버튼에 **Yes (Y)** / **No (N)**를 표시합니다. 기본 선택은 No이며, 처음 열린 상태에서 Enter를 누르면 취소됩니다. Tab으로 버튼을 바꾼 뒤 Enter를 누르면 선택한 버튼이 실행됩니다.
- 누르고 있던 Y의 키 반복은 삭제를 승인하지 않습니다. 이 단축키는 SFTP 삭제 확인창에만 적용합니다.
- 1.1.0의 탭 분리와 SFTP 파일 드래그앤드롭을 포함합니다.

## 검증과 제한

Windows 로컬 빌드, CTest 4종, 루프백 SFTP 및 탭·드래그 통합 검사 47개를 통과했습니다. 로컬·원격 파일에서 N/Esc/기본 Enter 취소와 Y 삭제, 반복 Y 무시를 Win32 키 메시지로 검증했습니다. Python 검사는 12개 통과, 환경 조건에 따른 1개 제외입니다.

전체 UI 회귀 검사는 이번 패치에서 재실행하지 않았습니다. 이전 1.1.0에서는 다른 앱의 화면 가림으로 실제 마우스 검사에서 중단되었습니다. 실제 탐색기 드롭·창 사이 드롭 위치 판정·다중 모니터 배율·NGS 수동 검증은 미실행입니다. Windows EXE는 미서명이며 macOS·iPad 및 GitHub Actions는 실행하지 않았습니다.
