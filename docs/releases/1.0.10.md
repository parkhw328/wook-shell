# 1.0.10 — SFTP 인증창 종료 후 포커스 복귀

- SFTP의 OTP·비밀번호 입력창에서 **Enter**로 제출하면 wShell이 뒤로 밀리던 문제를 수정했습니다. 별도 프로세스의 인증창을 닫기 전에 원래 작업 공간을 전경으로 돌려줍니다.
- **Esc** 취소도 같은 복귀 처리를 사용합니다. 사용자가 다른 창으로 전환한 경우에는 해당 창의 포커스를 유지합니다.
- 같은 프로세스의 이름 변경·키 암호 입력창은 소유 창을 먼저 다시 활성화 가능하게 만든 뒤 닫고, 기존 입력 포커스를 복원합니다. Enter·Esc 처리는 해당 입력창과 그 컨트롤에만 적용합니다.
- [1.0.9의 어두운 SFTP 스크롤바와 F2·Delete·F5 단축키](1.0.9.md)를 포함합니다.

## 검증과 제한

- Windows x64 EXE와 테스트 EXE를 Linux에서 교차 빌드하고, 단일 EXE ZIP·SHA-256·내장 리소스·시스템 DLL 의존성을 정적으로 검증했습니다.
- 배포 무결성 Python 테스트 8개와 새 SSH 테스트 스크립트의 구문 검사를 통과했습니다.
- `node tests/ssh/sftp-auth-integration.cjs` 회귀 검사를 추가했습니다. 잠기지 않은 Windows 데스크톱에서 실제 키 입력으로 다중 OTP의 Enter 제출, 중복 없는 서버 응답, Esc 취소, SFTP 목록으로의 포커스 복귀와 다른 창의 포커스 보존을 확인합니다.
- **이번 OTP 수정의 Windows UI·SSH 실행 검사와 스크린샷 검사는 아직 수행하지 않았습니다.** 1.0.9의 사용자 테스트 완료 보고는 이번 수정본의 실행 검증을 의미하지 않습니다.
- NGS 환경 수동 검증, macOS·iPad 빌드와 GitHub Actions는 실행하지 않았습니다. EXE는 미서명입니다.
