# 1.2.2 — SFTP 경로 입력 Enter 지원

## 변경 사항

- **LOCAL 경로 입력칸에서 Enter**를 누르면 왼쪽 **Go**를 실행합니다.
- **REMOTE 경로 입력칸에서 Enter**를 누르면 오른쪽 **Go**를 실행합니다. 반대편 경로 입력값은 실행하지 않습니다.
- 기존 Go 버튼의 이동·오류 처리와 활성 조건을 사용합니다. 연결·전송 작업 중이나 드래그 중에는 이동하지 않습니다.
- Enter를 길게 누른 반복 입력으로 중복 이동하지 않습니다. Tab과 일반 텍스트 편집 동작은 유지합니다.
- 1.2.1의 SFTP 권한 오류 후 연결 유지 및 Refresh/F5 재연결 수정을 포함합니다.

## 검증과 제한

- Windows x64 앱과 테스트 EXE를 Linux에서 교차 빌드했습니다. 단일 EXE ZIP·내장 폰트/라이선스/아이콘·시스템 DLL 의존성 정적 검사를 통과했습니다.
- Python 도구 테스트 16개, 통합 테스트 JavaScript 구문 검사, `git diff --check`를 통과했습니다.
- `node tests/ssh/sftp-error-integration.cjs`에 Local/Remote Enter 이동, 반대편 목록 보존, 키 반복 방지, 작업 중 이동 차단 검사를 추가했습니다. Windows 대화상자 키 라우팅을 거쳐 독립 루프백 SFTP 서버의 폴더를 탐색합니다.
- **Windows 실제 키보드·UI·SSH 통합 테스트 및 스크린샷 확인은 이 Linux PC에서 실행하지 않았습니다.** 테스트 EXE 컴파일과 실행 검증을 구분합니다. NGS 실기 검증도 미실행입니다.
- macOS·iPad 빌드와 GitHub Actions는 실행하지 않았습니다. Windows EXE는 미서명입니다.
