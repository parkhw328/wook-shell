# 1.2.3 — 작업 공간 종료 Y/N 단축키

## 변경 사항

- 활성 연결이 있는 작업 공간의 종료 확인창에 **Yes (Y) / No (N)**을 표시합니다.
- `Y`는 해당 창 종료와 활성 연결 해제, `N` 또는 `Esc`는 취소합니다. 버튼 포커스와 관계없이 Y/N으로 선택할 수 있습니다.
- 기본 선택은 **No**입니다. 처음 열린 상태에서 Enter는 취소하며, 버튼 포커스를 옮긴 뒤 Enter는 해당 버튼을 실행합니다.
- 길게 누른 Y의 반복 입력은 승인으로 처리하지 않습니다. Ctrl/Alt 조합도 Y/N 단축키로 실행하지 않습니다.
- 기존 SFTP 삭제 확인창과 같은 단축키 처리를 재사용합니다. 1.2.2의 SFTP 경로 Enter 이동과 이전 권한 오류 복구도 포함합니다.

## 검증과 제한

- Windows x64 앱·테스트 EXE를 Linux에서 교차 빌드하고 단일 EXE ZIP·내장 리소스·시스템 DLL 의존성 정적 검사를 통과했습니다.
- Python 도구 회귀 테스트 16개와 `git diff --check`를 통과했습니다.
- `node tests/ssh/message-integration.cjs`의 메시지 검사에 종료 확인창의 Y/N·Esc·기본 Enter, No 기본 포커스, 버튼 레이블, 반복 Y 무시 및 소유 창·포커스 복원을 추가했습니다.
- **Windows 실제 키보드·UI 실행 검사와 스크린샷 확인은 이 Linux PC에서 수행하지 않았습니다.** 테스트 EXE 컴파일을 실행 검증으로 표시하지 않습니다. NGS 실기 검증도 미실행입니다.
- macOS·iPad 빌드와 GitHub Actions는 실행하지 않았으며 Windows EXE는 미서명입니다.
