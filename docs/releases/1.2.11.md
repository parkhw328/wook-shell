# 1.2.11 — 키 입력 시 최신 터미널 화면 복귀

## 변경 사항

- 이전에는 Enter만 화면 복귀를 강제했고 일반 키 입력의 `scroll_on_key` 기본값은 꺼져 있었습니다. 이제 문자·한글·방향키 등 터미널 입력 시 최신 화면으로 돌아가도록 기본값을 켭니다. 서버 에코를 기다리지 않고 기존 엔진의 스크롤·화면 갱신 처리를 사용합니다.
- `WookScrollOnKey` 설정 키로 이전 `ScrollOnKey=0` 연결에도 새 기본값을 적용합니다. 사용자 설정 파일을 일괄 수정하지 않습니다. `Reset scrollback on keypress`를 명시적으로 끄면 새 키에 저장되어 재접속에도 유지됩니다. Enter·숫자 키패드 Enter의 강제 복귀는 유지합니다.
- 서버 출력만 들어올 때는 위 기록의 위치를 유지합니다. 단독 수정 키·기록 탐색·작업 공간 단축키처럼 터미널 입력을 보내지 않는 동작은 복귀시키지 않습니다. 동기화 입력도 각 대상의 엔진 설정을 따릅니다.

## 검증과 제한

- Linux Python 회귀 검사 30개 통과. 새 기본값·저장 키와 실제 엔진 키 이벤트 함수의 스크롤 복귀·화면 갱신·명시적 해제 동작을 검사했습니다.
- SSH/UI 회귀에 서버 에코 없는 일반 문자·한글·방향키와 대체 화면 문자 입력의 복귀 및 SSH 전달 횟수 검사를 추가했습니다. JavaScript 구문 검사 통과.
- Windows x64 교차 빌드·테스트 EXE 컴파일 및 배포 ZIP·리소스·시스템 DLL·해시 정적 검사를 수행합니다.
- Linux 환경이므로 Windows SSH/UI 실행 검사·실제 키보드/IME 입력·화면 캡처는 미실행입니다. Windows에서는 `node tests/ssh/scroll-integration.cjs` 및 `--follow-output` 조합으로 후속 검증할 수 있습니다. macOS·iPad 및 GitHub Actions는 실행하지 않습니다.
