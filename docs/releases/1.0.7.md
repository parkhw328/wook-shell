# 1.0.7 — Enter 입력 시 최신 화면으로 스크롤 복귀

- 위쪽 스크롤 기록을 보다가 Enter 또는 숫자 키패드 Enter를 누르면 최신 화면으로 돌아갑니다. 서버의 응답이나 에코를 기다리지 않습니다.
- `Reset scrollback on keypress`가 꺼진 기존 연결에도 적용합니다. 일반 문자 입력과 서버 출력의 기존 스크롤 정책은 유지합니다.
- 키보드 동기 입력 대상에도 Enter 스크롤 복귀를 적용합니다. 작업 공간 단축키로 처리되는 입력은 터미널 전송 경로에 들어가지 않습니다.
- [1.0.6의 SFTP 깜빡임·전송 병목 수정](1.0.6.md)을 포함합니다.

## 검증과 제한

- 일반 화면과 대체 화면에서 Enter 복귀, 숫자 키패드 Enter, 서버 에코 없는 복귀 및 SSH 입력 중복 여부를 검사하도록 Windows 회귀 테스트를 확장했습니다.
- Windows x64 EXE와 테스트 EXE를 Linux에서 교차 빌드하고 단일 EXE ZIP·해시·내장 폰트/브랜딩/라이선스·시스템 DLL 의존성을 정적으로 검증했습니다. Python 테스트 13개도 통과했습니다.
- Windows UI·SSH 실행 검사, 실제 화면 캡처와 NGS 수동 검증은 미실행입니다. 추가한 회귀 테스트는 컴파일했으며 이 환경에서 실행하지 않았습니다.
- macOS·iPad와 GitHub Actions는 실행하지 않았습니다. EXE는 미서명입니다.
