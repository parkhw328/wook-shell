# 1.0.11 — 공통 스크롤바 테마 적용

- 왼쪽 호스트 네비게이션의 스크롤바가 흰색으로 나타나던 부분을 수정했습니다. SFTP에만 적용했던 처리를 공통 컨트롤 테마로 옮겼습니다.
- 키 관리 목록·공개키 텍스트, 라이선스 본문, 설정 화면의 입력칸·드롭다운 팝업과 SFTP 목록에 함께 적용합니다. 항목이 늘거나 창이 작아져 나중에 나타나는 가로·세로 막대와 교차 모서리도 같은 테마를 사용합니다.
- 별도 프로세스의 터미널 스크롤바와 이벤트 로그에도 적용했습니다. 이벤트 로그의 본문과 배경도 앱의 어두운 색상에 맞췄습니다.
- Windows의 기본 스크롤·휠·키보드 동작을 유지합니다. 설정 페이지와 긴 알림창의 기존 사용자 정의 스크롤바는 이미 앱 색상을 사용합니다. 운영체제가 제공하는 파일·글꼴 선택 대화상자는 Windows 기본 표시를 따릅니다.
- [1.0.10의 SFTP OTP 인증창 포커스 복귀 수정](1.0.10.md)을 포함합니다.

## 검증과 제한

- Windows x64 앱과 테스트 EXE를 Linux에서 교차 빌드하고, 단일 EXE ZIP·SHA-256·내장 리소스·시스템 DLL 의존성을 정적으로 검증했습니다.
- 배포 무결성 Python 테스트 8개, 패치 스크립트와 새 테스트 실행 스크립트의 구문 검사를 통과했습니다.
- Windows 회귀 검사에 넘치는 호스트 목록, 목록·텍스트·파일 목록·콤보 팝업의 실제 스크롤바 및 모서리 픽셀 밝기, 가로·세로 이동, 크기·테마 변경을 추가했습니다. 실제 설정 드롭다운과 별도 엔진의 터미널·이벤트 로그도 검사 대상으로 추가했습니다.
- **이번 수정의 Windows 화면·UI·SSH 실행 검사와 스크린샷 확인은 아직 수행하지 않았습니다.** 테스트 EXE 컴파일과 실제 Windows 실행 검증을 구분합니다.
- NGS 환경 수동 검증, macOS·iPad 빌드와 GitHub Actions는 실행하지 않았습니다. EXE는 미서명입니다.
