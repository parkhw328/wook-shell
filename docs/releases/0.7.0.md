# wShell 0.7.0

Windows and macOS now display existing tabs in **2, 3 or 4 panes**.

- Use **Split** for two columns, a large left pane with stacked right panes, or a 2×2 grid.
- Click a pane to focus it; commands affect that tab only. Selecting a hidden tab replaces the active pane while keeping other sessions running.
- Return to **Single pane** without disconnecting. Tab order changes and closing panes retain the remaining connections.
- `Ctrl+Shift+S` on Windows and `⌘⇧S` on Mac open the layout menu.
- SFTP adds **Show hidden files**, unchecked by default, for both local and remote lists. Dotfiles/folders and local OS hidden flags are respected.
- Native tests cover separate terminal input, non-overlapping geometry, switching, tab reordering and returning to single-pane mode.

See [split-view usage](../split-view.md). This version uses fixed pane proportions; input broadcasting and draggable dividers are not included.

Windows is a single unsigned `wShell.exe`. macOS is a universal, ad-hoc-signed `wShell.app` (macOS 13+, Intel and Apple Silicon), without Developer ID notarization. Settings remain in AppData/Application Support. Passwords and private keys are excluded from settings export/import.

The separately versioned iPad personal preview is described in [the iPad guide](../ipad.md); an unsigned IPA requires the user's own Apple-account signing and is not a directly installable desktop artifact.
