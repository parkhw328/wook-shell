# wShell 0.8.0

Windows and macOS add host aliases, color identifiers and split-terminal command broadcasting.

- Set an optional **Alias** and **Tab color** in the host editor. Saved host names and authentication identities remain independent of the alias. Colors appear in tabs and split headings; Windows also colors pane borders.
- The bottom split-view command bar sends one line plus Enter to the active terminal. Enable **Send to all panes** to target all visible connected terminals.
- Enable **Sync keyboard** to mirror terminal typing, cursor keys, Backspace, Ctrl+C and paste. IME composition is local; only committed text is sent.
- Both modes default off and reset when the visible pane group changes. Hidden tabs, SFTP, previews and unauthenticated sessions are excluded. No input history is stored.

These controls send the same input; they do not synchronize remote shell state, working directories or command completion. Application shortcuts, mouse actions and scrollback are not broadcast.

See [split-view usage](../split-view.md). iPad remains at personal preview 0.1.0; these additions target Windows and Mac.
