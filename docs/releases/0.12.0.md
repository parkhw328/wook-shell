# wShell 0.12.0 — Windows

- 탭 우클릭에 나머지 탭·오른쪽 탭·모든 탭 닫기를 추가했다. 전체 탭 메뉴에서도 나머지·모두 닫기를 실행할 수 있다. 실행 중인 세션은 한 번만 확인하며, 취소하면 분할과 입력 초안을 유지한다. 메뉴가 열린 동안 탭이 바뀌어도 원래 탭 ID로 대상을 추적한다.
- 호스트 목록 접기 버튼을 상단 메뉴에서 `CONNECTIONS` 옆으로 옮겼다. 접힌 상태에서는 왼쪽의 좁은 탐색 영역에 펼치기 버튼을 남긴다.
- 설정 페이지를 다시 그릴 때 빈 배경까지 갱신해 이전 항목의 잔상이 남지 않도록 했다. 호스트 편집·키 관리자·입력창과 편집형 콤보박스의 배경 그리기가 내부 입력 내용을 덮지 않도록 수정했다.
- Oracle PEM RSA `.key`를 포함한 OpenSSH·기존 PEM 개인키를 호스트 저장·접속과 Host Settings에서 가져올 수 있다. 원본을 유지하면서 PPK 사본을 등록하고, 키 관리자의 등록 목록과 `Use key`로 재사용한다. 파일 확장자가 아닌 내용을 판별하며 공개키만 있는 파일은 거부한다.
- 키 파일은 현재 사용자와 SYSTEM만 접근할 수 있도록 보호하며, 가져온 키의 암호화를 유지한다. 키 암호와 개인키는 설정 백업에 포함하지 않는다.
- 개인키를 기록하기 전에 열린 파일의 접근 권한을 직접 적용하고 상속 차단 상태를 확인한다. 권한을 보장할 수 없으면 빈 임시 파일을 지우고 저장을 중단한다.

## 검증

- 탭 일괄 닫기의 취소·한 번의 확인·탭 교체 경쟁 조건, 실제 자식 세션 종료와 단일 보기 복귀.
- 최소·큰 창의 탐색·탭 배치, 32개 Host Settings 페이지의 경계와 겹침, 페이지 잔상 제거와 입력칸의 다시 그리기.
- PEM RSA, 암호화된 PEM RSA와 OpenSSH Ed25519 등록·암호 유지·파일 권한·원본 보존·잘못된 키 거부. 독립 루프백 SSH 서버에서 변환 키 3개와 배포 EXE의 접속·재접속 서명 2개 검증.
- 기존 핵심·IME·SSH·SFTP·폰트·실행 인자·분할 입력 회귀 검사.

Windows 로컬 검증: 핵심 872건, IME 20건, SFTP 프레이밍 22건, 작업 공간 UI 407건, Host Settings 32개 페이지의 4,152건을 통과했다. 키 등록 검사는 29건과 독립 서버의 SSH 서명 5건을 통과했다.
