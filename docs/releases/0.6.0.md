# wShell 0.6.0

- Add native SFTP tabs on Windows and macOS, with local and remote file lists side by side, UTF-8 paths, folder navigation, multiple-file upload/download, progress and cancellation.
- Create folders, rename items and delete files or empty folders in either pane. Confirm existing-file replacement and permanent deletion.
- Reuse saved SSH keys, host trust and scoped DPAPI/Keychain passwords. SFTP opens an independent connection; terminal tabs remain usable during transfers.
- Stage downloads locally and uploads remotely before completing them. Existing remote files require the server's atomic POSIX rename extension. Interrupted uploads can leave `.wshell-*.part` files; completed files are not rolled back.
- Share one bounded SFTP v3 codec across platforms. Test protocol framing, malformed replies, UTF-8 names, out-of-order/short reads, exact file contents, cancellation and native UI operations against an independent loopback SSH server.

Use **SFTP** beside a saved host's Connect button, **Files** in a Windows SSH tab, or **Tools → Open SFTP** on macOS. See [the SFTP guide](../sftp.md) for usage and limitations. Recursive folder transfers, synchronization, resume, drag-and-drop, remote editing and permission changes are not included in this release.

Windows remains a single `wShell.exe`. macOS remains a Universal `wShell.app` for macOS 13+, ad-hoc signed and not notarized. Settings remain in AppData / Application Support. **Export / Import excludes passwords and private keys.**
