# wShell

**여러 서버의 SSH 접속과 파일 전송을 한 창에서 관리하는 네이티브 터미널입니다.**
Windows는 설치 없이 `wShell.exe` 하나로 실행합니다. Flexoki Dark 테마와 JetBrains Mono 폰트를 기본 제공합니다.

[Windows 다운로드](https://github.com/parkhw328/wook-shell/raw/refs/heads/main/release/latest/windows-x64/wShell.exe) · [전체 다운로드](release/README.md) · [상세 사용법](docs/usage.md) · [문제 신고](https://github.com/parkhw328/wook-shell/issues)

![wShell 작업 공간](assets/screenshots/workspace.png)

## 주요 기능

- SSH 연결 저장·검색과 탭 관리
- 2·3·4분할 화면과 여러 서버에 공통 입력
- SFTP 파일 전송과 SSH 개인키 관리
- CMD·PowerShell 로컬 터미널

Windows 10 1903 이상·Windows 11 x64에서 사용할 수 있습니다. 현재 Windows 배포는 Linux 교차 빌드이며 정적 검사를 통과했습니다. Windows 실행 검증 범위는 릴리스 노트에서 확인할 수 있습니다. macOS는 기존 배포를 유지하고, macOS·iPad 새 빌드는 중단되어 있습니다.
