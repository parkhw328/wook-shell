# iPad 개인용 버전

- `ios/`는 iPadOS 17 이상용 네이티브 SwiftUI/UIKit 앱이다. `ios/VERSION`으로 데스크톱과 별도 관리한다.
- 내장 libssh2와 OpenSSL, SwiftTerm을 사용한다. 버전·커밋·다운로드 SHA-256은 `scripts/build-ios.py`에 고정한다. 암호화를 직접 구현하지 않는다.
- Keychain의 `WhenUnlockedThisDeviceOnly`, 비동기화 항목에 비밀번호·개인키를 저장한다. 키 암호는 저장하지 않는다. 암호를 인수·환경변수·임시 파일에 전달하지 않는다.
- 자격 증명을 보내기 전에 SHA-256 호스트 키를 확인한다. 기존 키 불일치는 차단하고 사용자의 별도 확인 없이 교체하지 않는다.
- 설정 백업은 비밀번호·개인키·호스트 키 신뢰를 제외한다. 내보내기·가져오기 전후에 안내한다. iPad 백업 형식은 데스크톱 WSB1과 다르다고 명시한다.
- SFTP는 공통 C 코덱과 파일 단위 전송 정책을 재사용한다. iOS 문서 선택기의 보안 범위 접근을 종료하고 로컬 파일은 앱 Documents/Files 안에 둔다.
- UI/Keychain은 메인 스레드에서, SSH와 파일 전송은 연결별 직렬 작업 큐에서 처리한다. 백그라운드 진입 시 연결을 종료한다.
- iPad 빌드는 macOS CI에서 시뮬레이터 SSH/SFTP 테스트를 통과해야 한다. 실제 iPad 설치와 한글 입력기 검증은 별도로 구분한다.
- 배포 IPA는 unsigned로 명시한다. 개인 Apple 계정의 서명·설치는 사용자가 로컬에서 수행한다. Apple 비밀번호·인증서·프로비저닝 프로파일을 수집하거나 커밋하지 않는다.
- 무료 계정의 7일 만료를 안내한다. 개인용 설치에 App Store 배포나 유료 계정이 필수인 것처럼 안내하지 않는다.
