# 작업 공간 UI 규칙

Windows 작업 공간의 기본 동작과 회귀 검증 기준이다. macOS·iPad는 해당 플랫폼의 UI 규칙을 유지하며 기능 차이를 README에 명시한다.

## 탐색과 상단 메뉴

- 저장 연결 목록은 상단 `Hide hosts` / `Show hosts` 또는 `Ctrl+Shift+H`로 접고 펼친다. 상태는 사용자 데이터에 원자적으로 저장하고 재실행 시 복원한다.
- `New host`, `Connect`, `SFTP`, `Edit`, `Host settings`, `Tools`, `About`은 항상 상단에 같은 순서로 배치한다. 탐색창을 숨기거나 탭을 바꾸어도 위치가 변하지 않는다.
- 상단의 호스트 작업은 선택한 저장 연결을 대상으로 한다. 대상 이름·주소를 툴팁으로 설명하고 공간이 있으면 메뉴 오른쪽에도 표시한다. 세션 도구 모음의 `Files`, `Settings`는 활성 탭을 대상으로 한다.
- 선택한 연결이 없으면 Connect·SFTP·Edit을 비활성화한다. SFTP는 SSH에만 활성화한다. 비활성 버튼은 제거하지 않아 위치와 순서를 유지한다.
- 탐색창 표시 변경은 터미널 연결, 탭·분할 객체, 활성 영역, 동기화 대상과 옵션, 입력 중인 명령을 보존한다. 숨겨지는 검색·목록에 포커스가 있었다면 활성 터미널 또는 홈의 빠른 연결 칸으로 돌린다.
- `Ctrl+Shift+P`는 탐색창을 펼치고 검색 칸을 선택한다. 이미 명령창이나 터미널을 편집 중이라면 단순 레이아웃 변경이 포커스를 빼앗지 않는다.
- 최소 창 크기와 DPI 변경에서도 상단 작업 버튼이 겹치거나 잘리지 않아야 한다. Windows 버튼·키보드 탐색·비활성 상태와 툴팁을 유지한다.

## 검색과 안내 문구

- 검색은 이름, 별칭, 주소, 그룹, 사용자 이름을 대소문자 구분 없이 찾는다. 입력 안내는 `Name, alias, address…`, 툴팁은 전체 범위를 설명한다.
- 저장 연결이 없는 상태와 검색 결과가 없는 상태를 구분한다. 결과가 없을 때에는 연결 추가 대신 검색어 변경을 안내한다.
- 접힌 목록을 필터링하거나 새로고침해도 자동으로 펼치지 않는다. 검색 상태는 탐색창을 접었다 펼쳐도 유지한다.

## 글꼴과 저장소

- JetBrains Mono Regular/Bold 원본과 라이선스를 EXE에 포함한다. 설치되지 않은 PC에서도 오프라인으로 실행하고 Windows 기본 글꼴 선택 창에서 크기를 변경할 수 있어야 한다.
- `%LOCALAPPDATA%\wShell\fonts`에 내장 파일을 캐시한다. `WOOK_DATA_DIR`가 있으면 그 아래 `fonts`를 사용한다. EXE 옆 파일이나 시스템 글꼴 설치에 의존하지 않는다.
- 캐시 이름은 내장 파일의 SHA-256을 포함한다. 실제 내용이 내장 리소스와 일치하는지 확인하고, 없거나 손상되면 임시 파일 작성 후 원자적으로 교체한다. 여러 탭이 동시에 시작해도 불완전한 파일을 읽지 않아야 한다.
- `AddFontResourceExW(..., FR_PRIVATE, ...)`로 현재 프로세스에만 등록한다. 메모리 폰트 등록만으로 Windows의 글꼴 존재 여부 검증이 해결됐다고 간주하지 않는다. 시스템 글꼴 레지스트리를 수정하지 않는다.
- Windows 새 연결의 터미널 기본값은 9pt다. UI 본문 11pt 등 의미별 크기와 구분하며, 기존 호스트의 사용자 지정 크기는 유지한다.
- 저장·캐시·등록 실패는 조용히 무시하지 않고 사용자에게 알린다.

## 검증

- `tests/workspace_smoke.inc`: EXE만 있는 폴더에서 폰트 캐시·두 굵기 등록·Windows 기본 글꼴 선택 창의 9→13→9pt 변경, 검색 범위, 최소 크기 버튼 배치, 숨김·표시·검색 포커스를 검증한다.
- `tests/focus_smoke.inc`: 실제 키 입력으로 분할 터미널에서 탐색 단축키를 사용하고, 명령 초안·입력 모드·제외 대상·포커스와 입력 전달을 검증한다.
- `tests/core_test.cpp`: 탐색 설정 영속화, 새 기본 9pt, 사용자 지정 크기 보존을 검증한다.
- `node tests/ssh/font-integration.cjs`: 창을 띄우지 않고 실제 프로세스의 글꼴 등록, 캐시 재사용, 손상·누락 복구, 8개 동시 프로세스 시작을 검증한다.
- 사용자 데이터와 자격 증명을 건드리지 않도록 모든 UI·SSH·SFTP 검증은 격리 폴더와 루프백 서버를 사용한다. 펼친 화면·접힌 화면·최소 크기 화면을 캡처해 확인한다.
