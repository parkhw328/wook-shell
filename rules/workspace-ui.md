# 작업 공간 UI 규칙

Windows 작업 공간의 기본 동작과 회귀 검증 기준이다. macOS·iPad는 해당 플랫폼의 UI 규칙을 유지하며 기능 차이를 README에 명시한다.

## 탐색과 상단 메뉴

- 저장 연결 목록은 탐색창의 `CONNECTIONS` 옆 접기 버튼 또는 `Ctrl+Shift+H`로 접고 펼친다. 접힌 상태에서도 왼쪽의 좁은 탐색 영역에 펼치기 버튼을 남긴다. 버튼의 접근성 이름과 툴팁으로 `Hide hosts` / `Show hosts`를 설명한다. 상단 작업 메뉴에는 배치하지 않는다. 상태는 사용자 데이터에 원자적으로 저장하고 재실행 시 복원한다.
- `New host`, `Connect`, `SFTP`, `Edit`, `Host settings`, `Tools`, `About`은 항상 상단에 같은 순서로 배치한다. 탐색창을 숨기거나 탭을 바꾸어도 위치가 변하지 않는다.
- 상단의 호스트 작업은 선택한 저장 연결을 대상으로 한다. 대상 이름·주소를 툴팁으로 설명하고 공간이 있으면 메뉴 오른쪽에도 표시한다. 세션 도구 모음의 `Files`, `Settings`는 활성 탭을 대상으로 한다.
- 선택한 연결이 없으면 Connect·SFTP·Edit을 비활성화한다. SFTP는 SSH에만 활성화한다. 비활성 버튼은 제거하지 않아 위치와 순서를 유지한다.
- 탐색창 표시 변경은 터미널 연결, 탭·분할 객체, 활성 영역, 동기화 대상과 옵션, 입력 중인 명령을 보존한다. 숨겨지는 검색·목록에 포커스가 있었다면 활성 터미널 또는 홈의 빠른 연결 칸으로 돌린다.
- `Ctrl+Shift+P`는 탐색창을 펼치고 검색 칸을 선택한다. 이미 명령창이나 터미널을 편집 중이라면 단순 레이아웃 변경이 포커스를 빼앗지 않는다.
- 최소 창 크기와 DPI 변경에서도 상단 작업 버튼이 겹치거나 잘리지 않아야 한다. Windows 버튼·키보드 탐색·비활성 상태와 툴팁을 유지한다.
- 탐색창을 펼치거나 창 폭을 줄여 탭 표시 개수가 줄어들면 스크롤 위치를 조정해 활성 탭을 계속 보이게 한다.

## 탭이 많을 때

- 탭은 198에서 112 논리 픽셀까지 폭을 줄인다. 그보다 좁아져야 하는 경우 좌우 스크롤 버튼, 보이는 범위/전체 개수, 전체 탭 메뉴를 탭 줄 안에 표시한다. 숨겨진 탭을 하단 개수나 단축키만으로 추측하게 하지 않는다.
- 세로·가로 휠과 좌우 버튼으로 탭 줄을 이동한다. 고해상도 휠의 작은 입력은 누적한다. 터미널 본문 위에서는 원래 터미널 스크롤을 유지한다.
- 수동으로 탭 줄을 둘러볼 때 활성 탭·분할 구성·입력 초안·키보드 포커스를 바꾸지 않는다. 주기적인 레이아웃 갱신이 스크롤을 원위치로 돌리지 않는다.
- 탭 선택·추가·닫기·창 폭 변경은 활성 탭을 보이게 한다. 전체 탭 메뉴는 숨겨진 탭의 전체 이름과 주소를 제공하고 선택된 탭을 체크한다. 메뉴가 열린 동안 연결이 종료돼도 다른 탭을 잘못 선택하지 않는다.
- 지정한 탭 색상은 탭 폭에 걸친 색상 띠와 배경에 함께 표시한다. 활성 탭은 호스트 색상과 별개의 주황색 외곽선·하단 표시·굵은 이름으로 구분하며 작은 창에서도 유지한다.
- 최소 크기와 큰 창에서 32개 탭, 버튼 양끝, 휠 방향, Ctrl+Tab 계열 전환, 닫기와 활성 객체 보존을 `tests/tabs_smoke.inc`로 검증하고 화면을 캡처한다.

## 탭 일괄 닫기

- 탭 우클릭에서 `Close other tabs`, `Close tabs to the right`, `Close all tabs`를 제공한다. 전체 탭 메뉴에서도 현재 탭을 남기거나 모든 탭을 닫을 수 있다. 대상이 없으면 비활성화한다.
- 실행 중인 터미널·SFTP를 포함할 때는 대상 개수와 연결 종료 영향을 한 번만 확인한다. 기본 선택은 `Close`다. `Don't ask again when closing tabs`를 체크하고 닫기를 실행했을 때만 다음 확인을 생략한다. 취소·Esc·확인창 X는 설정·분할·활성 탭·명령 초안을 보존한다.
- `Tools → Application settings → Confirm before closing tabs`에서 확인을 복원하거나 해제한다. 설정은 현재 PC 사용자 저장소에 원자적으로 저장하고 다음 실행에도 유지한다. Settings의 Cancel은 저장하지 않는다. 이 옵션은 개별·일괄 탭 닫기에 적용하며 전체 앱 종료 확인은 별도로 유지한다.
- 확인한 원래 탭 ID만 닫는다. 메뉴·확인창의 중첩 메시지 루프에서 탭이 종료되거나 새로 열려도 인덱스나 재사용된 객체 주소로 다른 탭을 닫지 않는다.
- 기존 정상 종료 경로와 프로세스 정리를 사용한다. 마지막 탭을 닫으면 Workspace로 돌아가고, 하나만 남으면 단일 보기로 복귀한다.

## 설정 창과 대화상자 그리기

- 배경을 직접 그리는 부모 창은 `WS_CLIPCHILDREN`으로 입력칸·버튼을 보호한다. 편집 가능한 콤보박스의 내부 Edit도 배경 그리기에서 제외한다.
- 설정 페이지는 `WM_PAINT`에서 빈 배경까지 그린다. 페이지 교체 후 배경과 자식 컨트롤을 모두 갱신해 이전 페이지의 글자·테두리가 남지 않도록 한다.
- Host Settings의 전체 페이지에서 컨트롤 경계·겹침을 검사한다. 호스트 편집·키 관리자·편집형 콤보는 부모만 다시 그려도 입력 내용의 픽셀이 유지되는지 검증한다.

## 알림·확인·About

- Windows 알림·확인창은 `src/message_dialog.cpp`의 공통 Flexoki 테마를 사용한다. 기존 반환값·기본 버튼·취소 가능 여부·Help 콜백을 유지한다. 긴 본문은 선택·복사와 스크롤이 가능해야 한다.
- 창은 소유 창 중심에 배치하고 모달 동안 소유 창을 비활성화한다. 닫힌 뒤 이전 포커스를 복원하며 중첩 상세창은 바깥 모달을 해제하지 않는다.
- SSH 호스트 키 확인은 지문·변경 경고·상세 정보를 유지하고 기본 선택을 Cancel로 둔다. Accept만 신뢰 키를 저장하고 Connect Once는 저장하지 않는다.
- About에는 버전·저작권·오픈소스 안내와 개발자 이메일, GitHub 프로필, 소스 저장소 링크를 제공한다.
- `tests/message_smoke.inc`와 `node tests/ssh/message-integration.cjs`로 링크 대상·키보드 메시지·긴 한글·휠/스크롤 손잡이·150% DPI·실제 SSH 신뢰 저장을 확인한다.

## 검색과 안내 문구

- 검색은 이름, 별칭, 주소, 그룹, 사용자 이름을 대소문자 구분 없이 찾는다. 입력 안내는 `Name, alias, address…`, 툴팁은 전체 범위를 설명한다.
- 저장 연결이 없는 상태와 검색 결과가 없는 상태를 구분한다. 결과가 없을 때에는 연결 추가 대신 검색어 변경을 안내한다.
- 접힌 목록을 필터링하거나 새로고침해도 자동으로 펼치지 않는다. 검색 상태는 탐색창을 접었다 펼쳐도 유지한다.

## 글꼴과 저장소

- JetBrains Mono Regular/Bold 원본과 라이선스를 EXE에 포함한다. 설치되지 않은 PC에서도 오프라인으로 실행하고 Windows 기본 글꼴 선택 창에서 크기를 변경할 수 있어야 한다.
- `%LOCALAPPDATA%\wShell\fonts`에 내장 파일을 캐시한다. `WOOK_DATA_DIR`가 있으면 그 아래 `fonts`를 사용한다. EXE 옆 파일이나 시스템 글꼴 설치에 의존하지 않는다.
- 캐시 이름은 내장 파일의 SHA-256을 포함한다. 실제 내용이 내장 리소스와 일치하는지 확인하고, 없거나 손상되면 임시 파일 작성 후 원자적으로 교체한다. 여러 탭이 동시에 시작해도 불완전한 파일을 읽지 않아야 한다.
- `AddFontResourceExW(..., FR_PRIVATE, ...)`로 현재 프로세스에만 등록한다. 메모리 폰트 등록만으로 Windows의 글꼴 존재 여부 검증이 해결됐다고 간주하지 않는다. 시스템 글꼴 레지스트리를 수정하지 않는다.
- Windows 새 연결의 터미널 기본값은 9pt다. UI 본문 11pt 등 의미별 크기와 구분하며, 기존 호스트의 사용자 지정 크기는 유지한다.
- 저장·캐시·등록 실패는 조용히 무시하지 않고 사용자에게 알린다.

## 터미널 마우스와 클립보드

- Windows는 1.0.1부터 일반 드래그 자동 복사·우클릭 붙여넣기를 우선한다. `Window/Selection`의 `Prefer mouse copy and paste`로 연결 중 적용하거나 호스트 설정에 저장한다.
- 새 `WookMouseClipboard` 키의 기본값은 켜짐이다. 기존 세션 파일을 일괄 수정하지 않고, 키가 없는 이전 연결에도 같은 기본값을 적용한다. 명시적으로 끈 값은 저장·재접속 시 유지한다.
- 켜져 있으면 기존 엔진의 마우스 보고 차단과 시스템 클립보드 경로를 사용하며, 휠은 터미널 기록을 스크롤한다. 원격 앱이 다시 마우스 보고를 요청해도 드래그나 붙여넣기를 가로채지 못한다. Ctrl+우클릭 메뉴와 bracketed paste는 유지한다.
- 꺼져 있으면 기존 마우스 보고·버튼·클립보드 설정을 따른다. Shift override로 복사·붙여넣기를 할 수 있으며, 별도의 마우스 보고 차단 설정도 존중한다.
- Shift override는 버튼을 누르지 않은 포인터 이동에도 적용한다. 마우스 모드가 정리되지 않고 남아 있어도 복사·붙여넣기 우선 모드에서는 좌표를 보내지 않는다. 입력 문자열에서 좌표처럼 보이는 텍스트를 제거하는 방식으로 해결하지 않는다.
- Windows 1.0.2부터 출력 발생 시 스크롤을 맨 아래로 되돌리는 동작은 기본 해제다. 수동으로 위 기록을 보는 동안 위치를 유지하고 맨 아래에서는 새 출력을 계속 따라간다. 엔진의 기존 `scroll_on_disp` 설정을 사용하며 터미널 해석을 재구현하지 않는다.
- `scroll_on_disp`는 새 `WookScrollOnDisp` 키로 저장한다. 이전 `ScrollOnDisp=1` 기본값이 저장돼 있어도 새 기본값을 적용하고, `Window`의 `Reset scrollback on display activity`에서 다시 켠 선택은 저장·재접속 시 존중한다. 실제 사용자 설정 파일을 일괄 수정하지 않는다.

## 검증

- `tests/workspace_smoke.inc`: EXE만 있는 폴더에서 폰트 캐시·두 굵기 등록·Windows 기본 글꼴 선택 창의 9→13→9pt 변경, 검색 범위, 최소 크기 버튼 배치, 숨김·표시·검색 포커스를 검증한다.
- `tests/focus_smoke.inc`: 실제 키 입력으로 분할 터미널에서 탐색 단축키를 사용하고, 명령 초안·입력 모드·제외 대상·포커스와 입력 전달을 검증한다.
- `tests/core_test.cpp`: 탐색 설정 영속화, 새 기본 9pt, 사용자 지정 크기 보존을 검증한다.
- `node tests/ssh/font-integration.cjs`: 창을 띄우지 않고 실제 프로세스의 글꼴 등록, 캐시 재사용, 손상·누락 복구, 8개 동시 프로세스 시작을 검증한다.
- `node tests/ssh/mouse-integration.cjs`와 `--application-mouse`: 기존 설정 파일·명시적 해제, 마우스 보고 중 드래그 복사·우클릭 한글 붙여넣기, Shift override, 설정 화면의 즉시 적용과 모드 종료를 Win32 메시지·시스템 클립보드·실제 루프백 SSH로 검증한다. OS 실제 입력 라우팅 검증과 구분한다.
- 마우스 회귀에는 any-event 마우스 이동과 앱이 대체 화면에서 돌아오면서 보고 모드를 남긴 경우를 포함한다. `node tests/ssh/scroll-integration.cjs`와 `--follow-output`은 실제 터미널 스크롤바를 켜서 관찰하며, 이전 설정의 새 기본값·명시적 자동 이동, 휠 단위 누적, 연속 출력 중 위치 유지·최하단 복귀, 대체 화면의 다시 그리기를 검사한다.
- 사용자 데이터와 자격 증명을 건드리지 않도록 모든 UI·SSH·SFTP 검증은 격리 폴더와 루프백 서버를 사용한다. 펼친 화면·접힌 화면·최소 크기 화면을 캡처해 확인한다.
